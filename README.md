# Priyanshu Yadav — Portfolio

A responsive personal portfolio website built using HTML and CSS.
It showcases my projects, skills, and contact information.

## Live Website

https://yadpriyanshu22-bot.github.io/devfolio/

## Run Locally

Follow these steps to run the portfolio website on your computer.

### 1. Clone the repository

Open a terminal and run:

```bash
git clone https://github.com/yadpriyanshu22-bot/devfolio.git
```

### 2. Open the project folder

After cloning the repository, move into the project directory:

```bash
cd devfolio
```

### 3. Open the website

Open the `index.html` file in a web browser.

The portfolio is built using HTML and CSS, so no additional dependencies or installations are required.
