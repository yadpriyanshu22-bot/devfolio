# Priyanshu Yadav — Portfolio

A responsive personal portfolio website built using HTML and CSS. It presents my projects, technical skills, and contact information in one place.

## Live Website

[https://yadpriyanshu22-bot.github.io/devfolio/](https://yadpriyanshu22-bot.github.io/devfolio/)

## About the Project

This portfolio was created to showcase my web development work and practice building responsive websites. It uses a simple layout to display project information and make contact details accessible.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design

## Projects

The portfolio includes the following projects:

- **Live Greeter**
- **Dynamic List Builder**
- **Warehouse Inventory**

## Responsive Design

The website uses CSS Flexbox and CSS Grid to organize its content. Media queries adjust the project grid layout for different screen sizes, helping the website work on desktop, tablet, and mobile devices.

## Run Locally

Follow these steps to run the portfolio on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/yadpriyanshu22-bot/devfolio.git
```

### 2. Open the project directory

```bash
cd devfolio
```

### 3. Open the website

Open the `index.html` file in your web browser.

The project uses HTML and CSS and does not require additional dependencies or installations.
